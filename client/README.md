# Gyanaegis client

## Development

Install dependencies and start the Vite development server:

```sh
npm install
npm start
```

The client is served at <http://localhost:5173>. The API is expected at
`http://localhost:5002/api`.

## Production build

Run `npm run build` to create the production bundle in `dist/`. Use
`npm run preview` to serve that bundle locally.
